# 04 — Resume from a vague Next

**Setup:** one feature `In progress` at `Pointer: 7.1 › 2/4`, `Next: continue implementing`, `Last done` naming a change in a real file; step list present.

**Prompt:** `/A.resume`

**Pass when all hold:**
- [ ] Reads the board, then the header and `## Context`, then the item — in that order.
- [ ] Verifies that the file named in `Last done` contains the described change (and reports if not).
- [ ] Says `Next` is vague and rewrites it as a concrete action naming file and change, derived from the step list.
- [ ] The announce block names feature › item › step, last done, next, awaiting.
- [ ] Continues at step 3 of 7.1 and nowhere else.
