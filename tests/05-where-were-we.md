# 05 — Where were we, in plain words

**Setup:** two features `In progress`, one `Planned`, one To do due today. Start a **new** chat so the conversation holds nothing.

**Prompt:** `where were we? what's pending?`

**Pass when all hold:**
- [ ] Opens the board and each in-progress header before answering.
- [ ] The reminder for the To do due today comes first, in one line.
- [ ] One line per in-progress feature with its pointer and next action; one line for the Planned feature with `Waiting on`.
- [ ] No statement that is not in a file read during this turn.
- [ ] Ends with one suggested next action, taken from a header's `Next`.
