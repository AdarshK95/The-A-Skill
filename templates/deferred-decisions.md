# Deferred decisions

_Decisions that were put off on purpose, with the reasoning and the condition that reopens them. A review finding or a design question was weighed and the answer was "not now, because X — but it matters again when Y". These are consequential: each one is a known gap the project is carrying knowingly. Not a to-do list (the board's Deferred and To do tables hold work with dates) and not the decisions log (those changed something). Append-only; newest at the bottom. Read before any work that touches the same part of the system, and check whether the reopening condition has arrived._
