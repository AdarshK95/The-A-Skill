# Constitution

_Standing rules every piece of work in this project is checked against. Agents read this first and never edit it; they propose wording, you add it. Keep it short: a rule earns its place when breaking it would be a defect._

## Principles

1. _(for example) Every fix ships for every environment; no dev-only or partial fixes._
2. _(for example) A change is verified by a check that fails if the change is wrong._

## Non-negotiables

- _(for example) No new dependency without a logged decision._
- _(for example) One path per purpose: a second route, helper or fetch for something an existing one reaches is removed or made to call the existing one._
- _(for example) Nothing that varies is hardcoded: URLs, keys, limits, paths and labels live in configuration._

## Conventions

- _(for example) Dates `DD MMM YY`, times `hh:mm AM/PM`._
